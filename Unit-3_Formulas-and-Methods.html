1.1 Hume-Rothery rules for complete solid solubility

Rule Condition
Size factor atomic radii differ by no more than about 15 %
Crystal structure same crystal structure
Valence similar valence
Electronegativity similar electronegativity

Percentage size difference (written in the Q&A model answer):

% size difference=rsolute−rsolventrsolvent×100\%\ \text{size difference}=\dfrac{r_{solute}-r_{solvent}}{r_{solvent}}\times100

1.2 Gibbs phase rule

P+F=C+NP+F=C+N

At constant pressure N = 1:

F=C+1−PF=C+1-P

  • Single phase, binary: F = 2 + 1 - 1 = 2.
  • Two phases, binary: F = 2 + 1 - 2 = 1.

1.3 Lever rule (two-phase region)

Tie line at the alloy temperature. C0 is the alloy composition.

WL=Cα−C0Cα−CLW_L=\dfrac{C_\alpha-C_0}{C_\alpha-C_L}

Wα=C0−CLCα−CLW_\alpha=\dfrac{C_0-C_L}{C_\alpha-C_L}

WL+Wα=1W_L+W_\alpha=1

Mass of a phase = fraction times total mass:

ML=WL MM_L=W_L\,M

Rule of thumb: the amount of a phase is the lever arm on the opposite side of C0.

Slide readings: C_L = 32, C_alpha = 43 and 31.5, 42.5. State which you use.

1.4 Solidification

Undercooling:

ΔT=Tm−Tactual\Delta T=T_m-T_{actual}

Free-energy change of a spherical nucleus:

ΔG=43πr3 ΔGv+4πr2 γsl\Delta G=\dfrac43\pi r^3\,\Delta G_v+4\pi r^2\,\gamma_{sl}

Critical radius:

r∗=2γslTmΔHf ΔTr^*=\dfrac{2\gamma_{sl}T_m}{\Delta H_f\,\Delta T}

More undercooling gives a smaller r. Smaller than r: embryo. Larger: nucleus.

2. Methods with one solved example each

Method 1. Gibbs phase rule: degrees of freedom

  1. Write the rule: P + F = C + N.
  2. Fix N: at constant pressure only temperature varies, so N = 1.
  3. Count components C and phases P at the point.
  4. Solve F = C + N - P.

Solved example: Cu-Ag alloy, single phase.

Given: C = 2, N = 1, P = 1.

F=C+N−PF=C+N-P

F=2+1−1F=2+1-1

F=2F=2

Answer: F = 2 (temperature and composition can both be changed without leaving the phase).

Two-phase region of a binary diagram (same rule, not worked on the slide):

F=2+1−2=1F=2+1-2=1

Method 2. Tie line and lever rule

  1. Locate the point (temperature, C0) on the diagram. Check it is in a two-phase region.
  2. Draw the horizontal tie line at that temperature.
  3. Read C_L (left end) and C_alpha (right end).
  4. Apply the lever rule: the fraction of a phase is the arm on the opposite side, divided by the whole tie line.
  5. Check that the two fractions add to 1.
  6. Multiply by 100 for percent, by the total mass for kilograms.

Solved example: 35 wt% Ni, 1250 deg C.

Given: C0 = 35, C_L = 32, C_alpha = 43 (read from the tie line on the slide).

To find: W_L and W_alpha.

WL=Cα−C0Cα−CLW_L=\dfrac{C_\alpha-C_0}{C_\alpha-C_L}

WL=43−3543−32W_L=\dfrac{43-35}{43-32}

WL=811=0.727W_L=\dfrac{8}{11}=0.727

Wα=C0−CLCα−CLW_\alpha=\dfrac{C_0-C_L}{C_\alpha-C_L}

Wα=35−3243−32W_\alpha=\dfrac{35-32}{43-32}

Wα=311=0.273W_\alpha=\dfrac{3}{11}=0.273

Check: 0.727 + 0.273 = 1.

Answer: 72.7 % liquid, 27.3 % alpha (the slide rounds to 73 and 27).

With the other reading (31.5 and 42.5): W_L = 7.5/11 = 0.68 and W_alpha = 3.5/11 = 0.32. State which reading you use.

Mass: for 10 kg of this alloy, M_L = 7.27 kg and M_alpha = 2.73 kg.

Method 3. Phase fractions in slowly cooled steel

  1. Find the carbon content C0 and compare with 0.76 wt%.
  2. If C0 is below 0.76: pro-eutectoid ferrite + pearlite. Use the austenite side (0.76) and ferrite (0.022).
  3. If C0 is above 0.76: pro-eutectoid cementite + pearlite. Use 0.76 and 6.67.
  4. Apply the lever rule just below 727 deg C.
  5. Check that the fractions add to 1.

The slides give no numerical example for steels. These examples are illustrations of the lever rule with the diagram values (0.022, 0.76, 6.67 wt% C), and are marked as such.

Method 4. Hume-Rothery size check

  1. Get the atomic radii of solute and solvent.
  2. Compute the percentage difference.
  3. Compare with the 15 % limit.
  4. Then check crystal structure, valence and electronegativity.

The course material gives the 15 % limit and the formula but no table of radii, so the example uses made-up round numbers, labelled as an illustration.

Illustration: r_solute = 1.15 and r_solvent = 1.00 (any consistent unit).

% size difference=1.15−1.001.00×100\%\ \text{size difference}=\dfrac{1.15-1.00}{1.00}\times100

% size difference=15 %\%\ \text{size difference}=15\ \%

Answer: right at the 15 % limit. Size alone allows extensive solubility only if the other three rules are also met.

Method 5. Classify an iron-carbon alloy by carbon

  1. Compare the carbon content (wt%) with the ranges below.
  2. If it is a steel, compare with 0.76 to name it hypo-, eutectoid or hyper-eutectoid.
Carbon (wt%) Name
below 0.008 iron
0.008 to 2.14 steel
2.14 to 6.7 cast iron

Example (illustration): 0.4 wt% C is between 0.008 and 2.14, so it is a steel. It is below 0.76, so it is hypo-eutectoid: ferrite + pearlite.

Method 6. Read the product from a cooling path on the TTT diagram

  1. Draw or note the cooling path against the start and finish curves.
  2. Does it enter the start curve? If not, the austenite stays until Ms.
  3. If it enters, note where: just below 727 deg C gives coarse pearlite, near the nose fine pearlite, lower gives bainite.
  4. If the path leaves before the finish curve, the rest of the austenite can turn to martensite below Ms.
  5. Compare the rate with the critical cooling rate (the path touching the nose).

Example (curve 7): the curve is tangent to the nose, so it is the critical cooling rate. Faster than this gives fully martensite. Slower gives at least some pearlite.
